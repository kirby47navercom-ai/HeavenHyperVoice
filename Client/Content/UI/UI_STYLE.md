# UI 작업 기준

2026-09-09: 사용자가 밝은 흰색/아이보리 중심의 전체 스타일 변경을 취소했다.
기존 화면은 스타일 변경 전으로 복원한다. 새 공통 디자인은 사용자가 나중에 정의한다.
여행 수첩 문구나 장식을 추가하지 않는다.

화면 배치와 스타일은 Widget Blueprint Designer에 저장한다.
C++ 부모는 입력, 창 우선순위, 데이터와 서버 연동을 담당한다.
통합 메뉴, 중앙 설정창, 분류별 스크롤 페이지와 기존 기능 연결은 유지한다.
필드 편성창도 WBP_FieldParty/WBP_FieldPartyEntry에서 편집한다.

## 플레이 중 창 우선순위

- UUEWindowWidget을 부모로 둔 창은 열거나 클릭하거나 키보드 포커스를 받으면 앞으로 온다.
- 창을 닫으면 남아 있는 창 중 마지막으로 사용한 창으로 입력이 돌아간다.
- 채팅은 미사용 시 불투명도 20%, 낮은 우선순위로 표시한다. 새 메시지 도착으로 앞으로 오지 않는다.
- 채팅을 클릭하거나 Enter로 입력을 시작하면 불투명도 100%로 앞으로 온다.
- 다른 창을 선택하면 채팅 입력을 멈추고 작성 중인 문장은 유지한다. Enter 전송/ESC 종료 시 문장을 비운다.
- 채팅 헤더 드래그는 유지한다. 더블클릭 축소/확장은 사용하지 않는다.
- 채팅 바깥의 게임 화면을 클릭하면 채팅 선택을 풀고 작성 중인 문장은 보존한다. 다른 창이 없고 G를 누르고 있지 않으면 커서를 숨기고 플레이 입력으로 돌아간다. 다른 UI 내부를 누르면 해당 창의 커서를 유지한다.
- 게임 화면에서 G를 누른 채 UI를 클릭하거나 Enter로 채팅을 열면, G를 놓아도 커서를 유지한다. 선택한 창을 닫으면 남아 있는 창에 따라 커서와 입력을 복원한다.
- G로 채팅을 선택하면 G를 놓은 뒤 입력칸에 포커스를 준다. 커서 조작 키의 반복 문자가 채팅에 들어가지 않으며, 이후 일반 G 입력은 그대로 사용할 수 있다.

새 독립 창은 UUEWindowWidget을 상속한 C++ 부모와 WBP를 사용한다.

월드의 포켓몬 체력바는 로컬 플레이어 기준 15m 이내에서만 표시한다.
BP_Pokemon의 Pokemon > UI > Health Bar Visible Distance에서 거리(cm)를 변경할 수 있다.
카드, 목록 항목, 로딩 화면, 표시 전용 HUD는 독립 창으로 등록하지 않는다.
채팅처럼 처음부터 떠 있는 수동 창은 Activate On Open을 끈다.

style_project_ui.py와 style_options_journey.py의 전체 스타일 적용은 중지했다.
사용자 요청에 따라 플레이/자동화 테스트는 실행하지 않는다.
로컬 서버/테스트 전용 변경은 커밋과 푸시에 포함하지 않는다.
