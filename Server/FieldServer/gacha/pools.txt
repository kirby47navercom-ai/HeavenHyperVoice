# 타입별 뽑기 후보와 가중치.
#
# 실제 확률 = 해당 weight / 그 타입 weight 합계. 서버가 합으로 나누므로 합이
# 얼마든 동작하지만, 1000 에 맞춰 적으면 weight 가 곧 천분율이라 읽기 쉽다.
#
#   entry <type> <dex> <rarity> <weight>
#     type    fire | water | grass | normal | electric
#     dex     전국도감번호. 서버 종족 표(Protocol/PokemonSpecies.h)에 있어야 한다.
#     rarity  normal | rare | super   — 클라이언트의 캡슐 색이 이걸로 정해진다
#     weight  정수. 0 이면 후보에서 빠진다.
#
# 기동할 때 검증한다. 종족 표에 없는 도감번호, 레이드 보스, 같은 타입에 같은
# 도감번호, weight 합이 0 인 타입이면 서버가 뜨지 않는다.
#
# 초기값은 Client/Scripts/Unreal/GACHA.md 의 표와 같다.
# 등급 합계는 일반 70% / 레어 25% / 슈퍼레어 5% 다.
